# TalkSpec

**Ясные ответы. Завершённая работа. Меньше лишних вопросов.**

Универсальные правила общения для AI-ассистентов. Без личного профиля, диагнозов и предположений о пользователе. Сценарии зависят от задачи: короткий вопрос, исследование, выбор, выполнение, обучение и диагностика ошибок.

## Подключение

Для постоянного применения используйте инструкции инструмента. Для вызова по необходимости — скилл. Установка скилла сама по себе не гарантирует его применение в каждом ответе.

| Инструмент | Способ подключения |
|---|---|
| ChatGPT | Вставить [полную](adapters/chatgpt/custom-instructions.txt) или [компактную](adapters/chatgpt/compact-instructions.txt) версию в пользовательские инструкции |
| Codex | Установщик: блок в `AGENTS.md` или скилл |
| Claude Code | Установщик: блок в `CLAUDE.md`; также есть скилл и плагин |
| Cursor | Установщик: правило проекта или скилл; для глобального режима — вставить [User Rules](adapters/cursor/user-rules.txt) |
| Grok и другие боты | Подключить [системное сообщение](adapters/grok/system-message.json) или [универсальный промпт](adapters/generic/system-prompt.md) в коде бота |

Нужен Python 3.9+. Зависимостей нет. Пример установки для Codex:

```bash
git clone https://github.com/aartem1/talkspec.git
cd talkspec
python3 scripts/install.py --tool codex --project /путь/к/проекту --dry-run
python3 scripts/install.py --tool codex --project /путь/к/проекту
```

Для Claude Code замените `codex` на `claude-code`, для Cursor — на `cursor`. `--mode skill` устанавливает скилл по необходимости. По умолчанию включается постоянный режим для указанного проекта. Если репозиторий закрыт, для клонирования и установки плагина нужны права доступа.

Установщик сохраняет сторонние инструкции и проверяет локальные правки перед обновлением или удалением. Удаление: повторите команду с теми же параметрами и добавьте `--uninstall`. Подробнее: [пути и команды](docs/installation.md).

## Принципы

- Главное — в начале; глубина соответствует запросу.
- Простой естественный язык с сохранением точности.
- Самостоятельное выполнение в рамках разрешений и доступных инструментов.
- Проверяемые утверждения и явная существенная неопределённость.
- Минимум лишних вопросов, повторений и переключений темы.

Краткость не должна скрывать важную информацию. Нет обязательных лимитов пунктов, пересказа статуса в каждом ответе или искусственного «следующего шага». Инструкции не добавляют инструментов и не разрешают внешние действия автоматически.

Все версии собираются из одного источника. [Описание подхода и источники](docs/design.md), [примеры для проверки поведения](evals/README.md), [English README](README.md).
